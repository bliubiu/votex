## GUI 交互设计

本文档定义 votex GUI 界面的交互流程、状态流转、错误提示规范和首次启动引导。



### 1. 全局交互规范

#### 1.1 窗口结构

```
┌─────────────────────────────────────────────┐
│  声阅                    ─ □ ✕            │
├─────────────────────────────────────────────┤
│  首页 | 语音合成(TTS) | 语音识别(ASR) | 批量任务 | 系统设置  │
├─────────────────────────────────────────────┤
│                                             │
│              页面内容区                       │
│                                             │
├─────────────────────────────────────────────┤
│  TTS: 已就绪 │ ASR: 未下载 │ ██████░░ 3/12  │
└─────────────────────────────────────────────┘
```

- 顶部：窗口标题栏（声阅）
- 导航栏：5 个主菜单标签页
- 中部：页面内容区（根据选中菜单切换）
- 底部：全局状态栏（常驻）

#### 1.2 导航规则

- 点击菜单标签切换页面，无二级导航弹窗
- 批量任务页内含子标签页（批量 TTS / 批量 ASR）
- 页面切换不丢失当前页面状态（如已输入的文本、已选参数）

#### 1.3 全局状态栏

| 区域 | 内容 | 交互 |
|------|------|------|
| TTS 模型状态 | 图标 + 文字（已就绪/未下载/加载中/加载失败） | 点击跳转系统设置 |
| ASR 模型状态 | 图标 + 文字（已就绪/未下载/加载中/加载失败） | 点击跳转系统设置 |
| 当前任务进度 | 进度条 + 阶段文字 | 无交互 |
| 任务统计 | 排队 N / 已完成 N / 失败 N | 点击跳转批量任务页 |



### 2. 首页（Dashboard）

#### 2.1 页面布局

```
┌──────────────────────────────────────────┐
│  ┌─────────────┐  ┌─────────────┐       │
│  │ TTS 模型状态  │  │ ASR 模型状态  │       │
│  │   已就绪 ✓   │  │  未下载 ✗    │       │
│  └─────────────┘  └─────────────┘       │
│                                          │
│  ┌──────────┐  ┌──────────┐             │
│  │ 快速配音   │  │ 快速识别   │             │
│  └──────────┘  └──────────┘             │
│                                          │
│  最近任务                                 │
│  ┌──────────────────────────────────┐   │
│  │ 1. TTS - novel.txt - 已完成       │   │
│  │ 2. ASR - meeting.mp3 - 已完成     │   │
│  │ ...                               │   │
│  └──────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

#### 2.2 模型状态卡片

| 模型状态 | 图标 | 颜色 | 操作按钮 |
|---------|------|------|---------|
| 已就绪 | ✓ | 绿色 | 无 |
| 未下载 | ✗ | 红色 | "下载模型"按钮 |
| 下载中 | ↻ | 蓝色 | 进度条 |
| 加载中 | ⋯ | 黄色 | 无 |
| 加载失败 | ✗ | 红色 | "重试"按钮 |

#### 2.3 快捷入口

- "快速配音"按钮：跳转到 TTS 页面
- "快速识别"按钮：跳转到 ASR 页面
- 模型未就绪时按钮置灰，hover 提示"请先下载模型"

#### 2.4 最近任务列表

- 展示最近 10 条任务记录
- 每条记录显示：类型图标 + 任务描述 + 状态 + 时间
- 点击记录可打开输出文件所在目录
- 无记录时显示"暂无任务记录"



### 3. 语音合成 TTS 页面

#### 3.1 页面布局

```
┌──────────────────────────────────────────┐
│  ┌────────────────────────────────────┐  │
│  │         文本编辑区                   │  │
│  │  （多行输入框 / 拖拽导入 TXT）       │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌──────────────┐  ┌──────────────┐     │
│  │  语音参数区    │  │  高级选项区    │     │
│  │  引擎/音色     │  │  拼接/停顿    │     │
│  │  语速/音调     │  │  降噪/编码    │     │
│  │  音量         │  │              │     │
│  └──────────────┘  └──────────────┘     │
│                                          │
│  [试听]  [开始合成]  [暂停]  [导出格式 ▼] │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │         音频播放器                   │  │
│  │  ▶ ━━━━━━━━━━━━━━━━━━━ 02:30/05:00│  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

#### 3.2 TTS 任务状态流转

```
空闲 → 合成中 → 已完成
  │       │
  │       ├── 暂停 → 暂停中 → 继续 → 合成中
  │       │
  │       └── 取消 → 已取消
  │
  └── 合成失败 → 可重试 → 合成中
```

#### 3.3 按钮状态

| 状态 | 试听 | 开始合成 | 暂停 | 导出格式 |
|------|------|---------|------|---------|
| 空闲 | 可用 | 可用 | 隐藏 | 可用 |
| 合成中 | 禁用 | 隐藏 | 可用 | 禁用 |
| 暂停中 | 禁用 | "继续" | 隐藏 | 禁用 |
| 已完成 | 可用 | "重新合成" | 隐藏 | 可用 |
| 已失败 | 可用 | "重试" | 隐藏 | 可用 |

#### 3.4 音频播放器交互

- 播放/暂停按钮：切换播放状态
- 进度条：显示当前播放位置，可拖拽跳转
- 时间显示：`当前时间 / 总时长`
- 音量滑块：调节播放音量
- 合成中播放器置灰，合成完成后自动加载音频



### 4. 语音识别 ASR 页面

#### 4.1 页面布局

```
┌──────────────────────────────────────────┐
│  ┌────────────────────────────────────┐  │
│  │         文件导入区                   │  │
│  │  （拖拽上传 / 选择文件按钮）         │  │
│  │  文件列表：文件名 | 时长 | 大小      │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌──────────────┐  ┌──────────────┐     │
│  │  识别参数区    │  │  输出配置区    │     │
│  │  模型/语种     │  │  格式/降噪    │     │
│  │  标点/切片     │  │              │     │
│  └──────────────┘  └──────────────┘     │
│                                          │
│  [开始识别]  [暂停]  [取消]  [导出]       │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │         识别结果预览区               │  │
│  │  （可编辑文本框，SRT 模式显示时间轴） │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

#### 4.2 ASR 任务状态流转

```
空闲 → 识别中 → 已完成
  │       │
  │       ├── 暂停 → 暂停中 → 继续 → 识别中
  │       │
  │       └── 取消 → 已取消
  │
  └── 识别失败 → 可重试 → 识别中
```

#### 4.3 文件导入交互

- 拖拽文件到导入区：自动检测格式，不支持的格式弹出提示
- 点击"选择文件"按钮：打开系统文件选择器，过滤支持的格式
- 已导入文件显示为列表，每行可删除
- 视频文件（MP4）显示"将自动提取音频"提示

#### 4.4 SRT 可视化编辑

- 识别结果以 SRT 格式显示，每条字幕一行
- 时间轴可点击编辑，弹出时间输入框
- 文字部分可直接在文本框内修改
- 修改后需点击"保存"按钮更新结果

### 7. 首次启动引导

#### 7.1 引导流程

```
欢迎页 → 模型下载页 → 导入页（可选）→ 完成页 → 首页
```

#### 7.2 欢迎页

- 软件名称"声阅"和版本号
- 简短介绍：离线语音工具，支持 TTS 配音和 ASR 字幕
- 离线模式说明：所有功能本地运行，不上传数据
- "下一步"按钮

#### 7.3 模型下载页

- 展示必需模型列表：

| 模型 | 大小 | 状态 | 操作 |
|------|------|------|------|
| Kokoro-82M（TTS） | ~100MB | 未下载 | [下载] |
| Whisper base（ASR） | ~140MB | 未下载 | [下载] |

- 可选模型：

| 模型 | 大小 | 状态 | 操作 |
|------|------|------|------|
| IndexTTS2（TTS 方言） | ~300MB | 未下载 | [下载] |
| Whisper small（ASR 高精度） | ~460MB | 未下载 | [下载] |

- 下载进度条显示
- "跳过"按钮（可跳过下载，后续在模型管理中下载）

#### 7.4 导入页

- 提示"已有模型文件？可手动导入"
- 文件选择器：选择本地模型文件
- 导入后自动校验

#### 7.5 完成页

- 显示模型状态摘要
- "开始使用"按钮 → 进入首页

#### 7.6 引导触发条件

- 首次启动：检测 `models/` 目录是否为空
- 为空 → 触发引导流程
- 不为空 → 直接进入首页
- 用户可在系统设置中手动重新触发引导（"重新引导"按钮）



### 8. 错误提示规范

#### 8.1 提示类型

| 类型 | 图标 | 颜色 | 用途 |
|------|------|------|------|
| 成功 | ✓ | 绿色 | 操作成功提示 |
| 警告 | ⚠ | 黄色 | 非致命问题提示 |
| 错误 | ✗ | 红色 | 操作失败提示 |
| 信息 | ℹ | 蓝色 | 一般信息提示 |

#### 8.2 提示展示方式

- **即时提示（Toast）**：操作反馈，3 秒后自动消失（如"已复制到剪贴板"）
- **对话框（Dialog）**：需要用户确认的操作（如"确认删除模型？"）
- **内联提示（Inline）**：表单字段旁的验证提示（如"文件格式不支持"）
- **状态栏提示**：底部状态栏的持久性信息（如任务进度）

#### 8.3 错误提示原则

- 提示文案使用简洁中文，说明问题和建议操作
- 不展示技术细节（如堆栈信息），技术细节写入日志
- 错误提示包含"查看日志"按钮（打开日志目录）
- 可重试的错误提供"重试"按钮

#### 8.4 常见错误提示文案

| 场景 | 提示文案 | 建议 |
|------|---------|------|
| 模型未下载 | "TTS 模型未下载，请先下载模型" | "前往下载"按钮 |
| 模型校验失败 | "模型文件校验失败，可能已损坏" | "重新下载" / "跳过校验" |
| 输入文件不存在 | "文件不存在：{文件名}" | 检查文件路径 |
| 文件格式不支持 | "不支持的文件格式：{扩展名}" | 列出支持的格式 |
| 磁盘空间不足 | "磁盘空间不足，需要 {大小} 可用空间" | 清理磁盘 |
| 推理失败 | "语音合成失败，请重试" | "重试"按钮 |
| 网络连接失败 | "网络连接失败，无法下载模型" | "检查网络" / "手动导入" |
| 编码不支持 | "文件编码不支持，请转换为 UTF-8 格式" | — |
