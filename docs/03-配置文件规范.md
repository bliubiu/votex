## 配置文件规范（application.yml）

votex 使用 YAML 格式的全局配置文件，位于程序同级目录 `application.yml`。

首次启动时自动生成带默认值的配置文件。



### 完整结构

```yaml
# ============================================
# votex 全局配置文件
# 修改后下次启动生效
# ============================================

# --- 模型配置 ---
models:
  # 模型文件存储根目录（默认 "models"）
  storage_path: "models"
  # 模型清单目录（可选，默认 {storage_path}/registry）
  # registry_path: "models/registry"
  # 下载配置
  download:
    # 镜像源优先级列表（按顺序尝试）
    priority:
      - modelscope
      - hf-mirror
      - github
      - huggingface
    # 单次下载超时（秒，默认 300）
    timeout: 300
    # 断点续传（默认开启）
    resume: true

# --- TTS 默认参数 ---
tts:
  # 默认引擎：kokoro / indextts25
  default_engine: "kokoro"
  # 默认音色（依赖引擎）
  default_voice: "xiaobei"
  # 默认语速：0.5 ~ 2.0
  default_speed: 1.0
  # 默认音调：-20 ~ +20
  default_pitch: 0
  # 默认音量：0 ~ 100
  default_volume: 80
  # 默认分段字数：300 / 500 / 800
  default_segment_size: 500
  # 段落间停顿时长（毫秒）：0 ~ 2000
  segment_silence_ms: 300
  # 交叉淡入淡出时长（毫秒）：0 ~ 200
  crossfade_ms: 50
  # 数字转中文（默认开启）
  num_to_chinese: true
  # 合成后自动播放
  auto_play: false
  # 合成后打开输出目录
  open_output_dir: false
  # 输出降噪（默认关闭，双引擎均可用）
  denoise: false
  # 降噪强度：low / medium / high
  denoise_level: "medium"

# --- ASR 默认参数 ---
asr:
  # 默认模型：base / small
  default_model: "base"
  # 默认语种：zh / zh-en
  default_language: "zh"
  # 自动添加标点（默认开启）
  auto_punctuation: true
  # 长音频自动切片（默认开启）
  auto_slice: true
  # 切片时长（秒）：15 / 30 / 60
  slice_length: 30
  # 输入降噪（默认关闭）
  denoise: false
  # 降噪强度：low / medium / high
  denoise_level: "medium"

# --- 输出配置 ---
output:
  # 默认导出目录
  default_dir: "文档/声阅"
  # 默认导出格式（不指定时由输出扩展名推断）
  default_format: "mp3"
  # MP3 默认比特率（kbps）：128 / 192 / 256 / 320
  mp3_bitrate: 192
  # WAV 默认位深：16 / 24
  wav_sample_depth: 16

# --- 日志配置 ---
log:
  # 日志级别：debug / info / error
  level: "info"
  # 日志输出目录
  dir: "logs"
  # 日志保留天数
  retention_days: 32
  # 终端输出
  console_output: true

# --- 界面配置 ---
ui:
  # 主题：light / dark
  theme: "light"
  # UI 缩放比例：0.75 ~ 2.0
  scale: 1.0
  # 窗口默认宽度（像素）
  window_width: 1200
  # 窗口默认高度（像素）
  window_height: 800

# --- 任务配置 ---
task:
  # 任务失败自动重试次数
  max_retries: 1
  # 重试间隔（秒）
  retry_delay: 5
  # 临时文件保留天数
  temp_retention_days: 7
  # 最近任务记录数上限
  recent_tasks_limit: 10

# --- 推理配置 ---
inference:
  # 推理线程数（0 表示自动：CPU 核心数 - 1）
  num_threads: 0

# --- 流水线配置 ---
pipeline:
  # 渐进式质量策略（默认开启）
  # 完成后提示用户可切换更高精度模型重跑
  progressive_quality: true

# GPU资源配置
gpu:
  enabled: false
  device_id: 0
  memory_fraction: 0.8

# 在线API 
api:
  azure:
    api_key: ENC(584ebc2bbccc74295fcc986fa218918ba8ae9e87b69a8b9c375ad9a17a8c691700871c421e28e9e2)

  pixabay:

video_material:
```

### 配置项说明

#### models

| 键 | 类型 | 默认值 | 说明 |
|----|------|--------|------|
| `storage_path` | 路径 | `models` | 所有模型文件的存储根目录 |
| `registry_path` | 路径 | `{storage_path}/registry` | 模型清单 YAML 文件目录（可选覆盖） |
| `download.priority` | 字符串数组 | `[modelscope, hf-mirror, github, huggingface]` | 镜像源优先级，按顺序尝试 |
| `download.timeout` | 整数 | 300 | 单次模型下载超时时间（秒） |
| `download.resume` | 布尔 | true | 是否启用断点续传 |

#### tts

| 键 | 类型 | 默认值 | 范围 | 说明 |
|----|------|--------|------|------|
| `default_engine` | 枚举 | kokoro | kokoro / indextts25 | 默认 TTS 引擎 |
| `default_voice` | 字符串 | xiaobei | 依赖引擎 | 默认音色名称 |
| `default_speed` | 浮点 | 1.0 | 0.5 ~ 2.0 | 默认语速 |
| `default_pitch` | 整数 | 0 | -20 ~ +20 | 默认音调 |
| `default_volume` | 整数 | 80 | 0 ~ 100 | 默认音量 |
| `default_segment_size` | 整数 | 500 | 300/500/800 | 默认分段字数 |
| `segment_silence_ms` | 整数 | 300 | 0 ~ 2000 | 段落间停顿时长 |
| `crossfade_ms` | 整数 | 50 | 0 ~ 200 | 交叉淡入淡出时长 |
| `num_to_chinese` | 布尔 | true | — | 数字转中文 |
| `auto_play` | 布尔 | false | — | 合成后自动播放 |
| `open_output_dir` | 布尔 | false | — | 合成后打开目录 |
| `denoise` | 布尔 | false | — | 输出降噪（双引擎均可用） |
| `denoise_level` | 枚举 | medium | low/medium/high | 降噪强度 |

#### asr

| 键 | 类型 | 默认值 | 范围 | 说明 |

| 键 | 类型 | 默认值 | 说明 |

### 配置优先级

命令行参数 > 配置文件 > 硬编码默认值

- 命令行未指定的参数，读取配置文件
- 配置文件未配置的项，使用硬编码默认值
- 配置文件格式错误时，使用默认值并输出警告日志
