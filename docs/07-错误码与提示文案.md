## 错误码与提示文案

本文档统一 votex 所有用户可见的错误码、CLI 输出文案和 GUI 提示文案。



### 1. 退出码（CLI）

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 成功 | 命令执行成功 |
| 1 | 参数错误 | 输入文件不存在、参数值非法、缺少必填参数等 |
| 2 | 模型未就绪 | 模型未下载、校验失败、加载失败 |
| 3 | 运行时错误 | 推理失败、磁盘空间不足、文件 I/O 错误 |
| 4 | 用户取消 | 用户按 Ctrl+C 取消操作 |



### 2. 错误码定义

错误码格式：`V{模块}{编号}`

- 模块编码：`M`（模型）、`T`（TTS）、`A`（ASR）、`C`（配置）、`S`（系统）
- 编号：3 位数字

### 3. CLI 输出格式规范

#### 3.1 错误输出

- 所有错误信息输出到 stderr
- 格式：`[错误] {中文描述}`
- 警告格式：`[警告] {中文描述}`
- 信息格式：`[信息] {中文描述}`

#### 3.2 进度输出

- 进度信息输出到 stderr
- 格式：`[进度] {阶段}: {当前}/{总数} ({百分比}%)`
- 示例：
  ```
  [进度] TTS 合成中: 3/12 (25%)
  [进度] ASR 识别中: 5/8 (62%)
  [进度] OCR 识别中: 文字检测...
  [进度] 模型下载中: 45MB/140MB (32%)
  ```

#### 3.3 结果输出

- 正常结果输出到 stdout
- TTS 合成成功：`[完成] 音频已保存至: {输出路径}`
- ASR 识别成功：`[完成] 识别结果已保存至: {输出路径}`
- OCR 识别成功：`[完成] 识别结果已保存至: {输出路径}`
- 模型下载成功：`[完成] 模型 {模型名} 下载完成`



### 4. GUI 提示文案规范

#### 4.1 文案原则

- 使用简洁中文，避免技术术语
- 说明问题 + 建议操作
- 不展示堆栈信息、错误码（错误码仅 CLI 使用）
- 提供可操作的按钮，而非纯文字提示

#### 4.2 提示类型与时长

| 类型 | 展示方式 | 时长 | 示例 |
|------|---------|------|------|
| 成功 | Toast | 3 秒 | "合成完成" |
| 警告 | Toast | 5 秒 | "磁盘空间不足 500MB" |
| 错误 | Dialog | 需确认 | "模型加载失败" + [重试] [查看日志] |
| 确认 | Dialog | 需确认 | "确认删除模型？" + [确认] [取消] |
| 验证 | 内联 | 持续 | "语速范围 0.5~2.0" |

#### 4.3 按钮文案规范

| 操作 | 文案 | 说明 |
|------|------|------|
| 确认 | 确认 / 确定 | 危险操作用"确认" |
| 取消 | 取消 | — |
| 重试 | 重试 | 失败后重新执行 |
| 下载 | 下载 | 模型下载 |
| 导入 | 导入 | 手动导入文件 |
| 保存 | 保存 | 保存设置/编辑 |
| 删除 | 删除 | 删除模型/任务 |
| 查看日志 | 查看日志 | 打开日志目录 |
| 跳过 | 跳过 | 跳过当前步骤 |
