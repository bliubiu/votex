# 29-实时听写、说话人分离与词级时间戳落地说明

> 本文记录三个 ASR 增强功能的设计与使用方式：
> **实时/流式听写**、**说话人分离**、**词级时间戳对齐**。
> 三者共用同一套领域层（DDD），CLI 与 GUI 完全对等。

## 1. 实时/流式听写

### 架构

```
麦克风（cpal 采集线程）
  → 单声道下混 + 线性插值重采样到 16kHz（infra::audio::capture::LinearResampler）
  → mpsc channel
  → 工作线程：StreamingAsrSession::accept_waveform（sherpa-onnx OnlineRecognizer）
  → DictationEvent { Started / Partial / Final / Stopped / Error }
  → CLI 终端打印 或 GUI 页面展示
```

- 领域接口：`votex-domain::asr::streaming`（`StreamingAsrProvider` / `StreamingAsrSession` / `StreamingUpdate`）
- 引擎实现：`votex-infra::asr::streaming::StreamingZipformerProvider`（流式 Zipformer transducer，中英混合，int8）
- 端点检测：句尾静音 2.4s（连续语音后 1.4s）自动定稿分句
- 用例编排：`votex-app::use_case::dictation_use_case::DictationUseCase`
  - 麦克风在工作线程内启动/停止（`cpal::Stream` 非 Send，不可跨线程移动）
  - 停止时冲刷残余音频（`finish`），全文落盘（UTF-8 txt）

### 使用

CLI：

```bash
votex dictate                       # 默认 streaming-zipformer，Ctrl+C 停止后终端打印全文
votex dictate -o 转写.txt            # 停止后保存到文件
```

终端输出约定：`○` 前缀为未定稿中间结果（单行覆盖刷新），`●` 为端点定稿文本。

GUI：「实时听写」页（语音处理分组）——选择模型、可选保存路径，开始/停止按钮，
中间结果灰字实时刷新，定稿文本逐段追加到可编辑转写区。

### 模型

模型清单 `models/registry/streaming-zipformer-zh-en.yaml`，落地目录
`models/asr/streaming-zipformer/`（tokens.txt + encoder/decoder/joiner，int8 优先）。

## 2. 说话人分离

基于 sherpa-onnx OfflineSpeakerDiarization（Pyannote 分割 + ERes2Net 嵌入 + AHC 聚类）。

### 集成方式

`AsrUseCase::recognize_ex(..., options, cancel)` 扩展入口：

1. 先完成常规 ASR（切片识别）得到字幕条目；
2. 对全音频（16kHz 单声道）执行分离，得到说话人时间轴片段；
3. 每条字幕按**时间重叠最大化**标注 `speaker`（`SubtitleEntry.speaker: Option<usize>`）；
4. 导出 `<output>.diarization.json`（说话人片段 + 数量）。

SRT / TXT 输出中，已标注条目带 `[说话人N]` 前缀（LRC 歌词场景不标）。

### 使用

```bash
votex asr -i 会议.wav -o 会议.srt --diarize                # 自动决定说话人数
votex asr -i 会议.wav -o 会议.srt --diarize --num-speakers 3  # 固定 3 人
```

GUI：「语音识别」页参数区勾选「说话人分离」，可设期望人数（0 = 自动）。

### 模型

模型清单 `models/registry/speaker-diarization.yaml`，落地目录
`models/asr/speaker-diarization/`（segmentation.onnx + embedding.onnx）。

## 3. 词级时间戳对齐

### 时间戳来源

`votex_infra::asr::recognize_output_from` 统一组装各引擎结果：

- Whisper / Paraformer / WeNet / FireRedASR（CTC 类）等 sherpa 引擎提供
  token 级时间戳 → **真实词级时间戳**（秒 → 毫秒，词终点 = 下一词起点）；
- SenseVoice 等不提供时间戳的引擎 → 整段伪时间戳（`start = end = 0`），
  下游据此识别为「未对齐」。

### 字幕组句规则（`group_words_into_entries`）

断句条件（任一命中即断）：句尾标点（。！？；.!?;）／累计 24 字符／累计 6 秒／
与前一词静音间隔超 600ms。拼接规则：CJK 连写，相邻英文词/数字间补空格。

### 使用

```bash
votex asr -i 播客.mp3 -o 播客.srt --words    # 精准字幕 + 播客.words.json
votex asr -i 播客.mp3 -o 播客.srt --words --diarize  # 组合使用
```

`words.json` 为绝对时间轴的词列表：`[{"word","start_ms","end_ms"}, ...]`。

GUI：「语音识别」页参数区勾选「词级时间戳对齐」。

## 4. 注意事项

- 说话人分离对长音频（>1 小时）耗时显著，属离线全量处理，无增量。
- 伪时间戳约定 `start_ms == end_ms == 0`；新增引擎接入时若带真实时间戳，
  走 `recognize_output_from` 即可自动参与对齐。
- 听写模型与 GUI 全局 task_tx 无关：听写页使用专属事件 channel，
  每帧非阻塞拉取（TaskEvent 无流式增量语义）。
- 麦克风采集在 Windows WASAPI 共享模式下按设备原生采样率采集，
  由 `LinearResampler` 重采样到 16kHz（44.1k/48k → 16k，线性插值精度对语音识别足够）。
