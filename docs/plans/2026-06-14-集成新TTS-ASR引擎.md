# 集成新 TTS/ASR 引擎实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 votex 集成 SenseVoice ASR（替换 Whisper）和 Qwen3-TTS（第二 TTS 引擎），同时引入 sherpa-onnx 作为统一 ASR 基础设施。

**Architecture:** 遵循现有 DDD 架构模式，domain 层新增 `EngineKind` 枚举变体、app 层 use_case 扩展引擎选择、infra 层新增 provider 实现（sherpa-onnx 包装 SenseVoice，Candle 包装 Qwen3-TTS），CLI 层扩展命令参数。

**Tech Stack:** Rust, sherpa-onnx (crate), qwen3-tts-rs (Candle), ort (已有), whisper-rs (已有)

### Task 2: 基础设施层 — sherpa-onnx 集成 (SenseVoice ASR Provider)

**Files:**
- Create: `crates/votex-infra/src/asr/sensevoice.rs`
- Create: `crates/votex-infra/src/asr/sensevoice_model.rs`（模型管理辅助）

- Modify: `crates/votex-infra/Cargo.toml`

**Step 1: 添加 sherpa-onnx 依赖**

```toml
sherpa-onnx = { version = "1.10", features = ["sense-voice"] }
```

**Step 2: 实现 SenseVoiceProvider**

遵循与 `WhisperProvider` 相同的 `AsrProvider` trait 实现模式：

```rust
pub struct SenseVoiceProvider {
    recognizer: Mutex<Option<OfflineRecognizer>>,
    sample_rate: u32,
}
```

实现 `AsrProvider` trait：
- `load()`: 从模型目录加载 ONNX 模型文件，创建 `OfflineRecognizer`
- `unload()`: 释放 recognizer
- `recognize()`: 通过 sherpa-onnx API 执行推理，返回 `RecognizeOutput`
- `sample_rate()`: 16000
- `is_loaded()`: 检查是否已加载

**Step 3: 注册模块**

在 `votex-infra/src/asr/mod.rs` 中添加：
```rust
pub mod sensevoice;
```

**Step 4: 模型下载支持**

在模型规范文档中添加 SenseVoice 模型定义：
- 模型 ID: `sense-voice`
- 来源: `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17-int8`
- 文件: `model.int8.onnx` + `tokens.txt`
- 大小: ~40MB

**Files:**

- Modify: `crates/votex-infra/src/tts/mod.rs`
- Modify: `crates/votex-infra/Cargo.toml`

**Step 1: 添加 qwen3-tts-rs 依赖**

```toml

```

注意：需要确认 crate 名称和 feature flags。备选方案是 `qts` (GGML+ONNX) 或 `qwen3_tts` (juntao)。

**Step 2: 实现 Qwen3TtsProvider**

遵循与 `KokoroProvider` 相同的 `TtsProvider` trait 实现模式：

```rust
pub struct Qwen3TtsProvider {
    model: Mutex<Option<Qwen3TTS>>,
    sample_rate: u32,
}
```

实现 `TtsProvider` trait：
- `load()`: 加载 Qwen3-TTS 模型（Candle CPU）
- `unload()`: 释放
- `synthesize()`: 调用 `model.generate_custom_voice_from_text()`
- `list_voices()`: 返回预设音色列表
- `sample_rate()`: 24000
- `is_loaded()`: 检查

**Step 3: 注册模块**

在 `votex-infra/src/tts/mod.rs` 中添加：
```rust
pub mod qwen3;
```

**Step 4: 模型下载支持**

添加 Qwen3-TTS 模型定义：
- 模型 ID: `qwen3-tts`
- 使用 CustomVoice 0.6B 版本（~1.8GB）
- 多个文件：模型权重、tokenizer、vocoder
