### Task 1: 音频降噪模块 (votex-infra/src/audio/denoiser.rs)

**Files:**
- Create: `crates/votex-infra/src/audio/denoiser.rs`
- Modify: `crates/votex-infra/src/audio/mod.rs` (添加 pub mod denoiser)

**设计：**
- 纯 Rust 实现，无 C++ 绑定
- 基础降噪：噪声门 (Noise Gate) — 低于阈值的静音段直接归零
- 中级降噪：频谱减法 (Spectral Subtraction) — FFT → 估计噪声谱 → 减去噪声 → IFFT
- `DenoiseLevel::Low` → 噪声门，`DenoiseLevel::Medium` → 频谱减法，`DenoiseLevel::High` → 两者叠加

**依赖评估：** rustfft + realfft 是纯 Rust，无原生库依赖，符合单二进制分发要求。

**Step 1: 添加 Cargo 依赖**

```toml

```

**Step 2: 创建 denoiser.rs**

}

impl Default for DenoiseConfig {
    fn default() -> Self {
        Self {

            fft_size: 1024,
            alpha: 0.95,

}

**测试用例：**
- 纯静音输入 → 输出不变

### Task 5: PipelineUseCase 真实实现

**Files:**
- Modify: `crates/votex-app/src/use_case/pipeline_use_case.rs`

**需要实现的阶段：**
1. **TextPreprocess**: 调用 TextSegmenter::preprocess()，去除多余空行/空白
2. **TextSegment**: 调用 TextSegmenter::segment() 分段
3. **TtsSynthesize**: 逐段合成 → 收集每个段的 AudioData（已有，但需返回 AudioData 而非写文件）
4. **AudioConcat**: WavWriter::write_concat() + 段落间静音插入
5. **AudioExtract**: 调用 ffmpeg 提取音频流（mp3.rs 已有 ffmpeg 工具）
6. **AudioSlice**: AsrUseCase::slice_audio() 逻辑
7. **AsrRecognize**: 复用现有 AsrUseCase
8. **SubtitleAlign**: 将 ASR 结果对齐到原始文本时间戳
9. **Export**: 复制/转换输出文件

**核心变更：** TTS 合成阶段需要改为返回 AudioData（复用现有 synthesize_segment），而非直接写文件 → 流水线内部数据传递使用 AudioData。
