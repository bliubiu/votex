## Votex（声阅）离线语音工具

### 项目定位

面向中文内容创作者（有声小说 / 视频配音 / 字幕制作）的离线桌面语音工具。v1 仅支持 Windows，CLI 与 GUI 功能完全对等，单二进制分发。



### 功能模块总览

| 模块 | 说明 |
|------|------|
| 模型管理 | TTS/ASR 离线模型的下载、导入、校验、切换 |
| 语音合成（TTS） | 文本转人声，支持朗读/配音，普通话 + 粤语 + 闽南语 |
| 语音识别（ASR） | 音频/视频转文字，输出纯文本/字幕 |
| 批量任务 | 批量 TTS 合成 + 批量 ASR 转写 |
| 配置中心 | 全局默认参数、主题、存储路径 |
| 任务队列 | 多任务排队执行，进度反馈，可暂停/取消 |
| 任务编排与流水线 | 多步骤任务编排，支持自动化流水线生成有声书/字幕 |



### 1. 模型管理

统一管理 TTS 和 ASR 离线模型，所有模型本地存储，不随二进制分发。

#### 1.1 TTS 模型

| 引擎 | 模型文件 | 大小参考 | 支持音色 | 方言 |
|------|---------|---------|---------|------|
| Kokoro‑82M | ONNX 格式 | ~100MB | 小北、云健等 8 种中文音色 | 普通话 |
| IndexTTS2 | ONNX 格式 | ~300MB | 见下方音色列表 | 普通话、粤语、闽南语 |

- 用户可自由切换 TTS 引擎，界面显示当前激活的引擎及音色列表
- 方言音色根据所选引擎动态展示可用列表（IndexTTS2 支持粤语/闽南语，Kokoro 仅普通话）
- 模型状态：未下载 / 下载中 / 加载中 / 已就绪 / 加载失败

#### 1.2 ASR 模型

| 引擎 | 模型 | 格式 | 大小参考 |
|------|------|------|---------|
| Whisper | base | ONNX（encoder+decoder） | ~90MB（含 encoder+decoder+tokens） |
| Whisper | small | ONNX（encoder+decoder） | ~280MB（含 encoder+decoder+tokens） |

- 双模型可选，small 准确度更高但推理更慢
- 支持自动下载和手动导入本地 ONNX 模型文件
- 模型完整性校验（SHA256）

#### 1.3 模型管理功能

- 一键自动下载（从官方源）
- 手动选择本地模型文件导入
- 模型完整性校验（下载/导入后自动校验，校验失败提示重新下载）
- 删除模型 / 重置缓存
- 下载支持断点续传

#### 1.4 模型存储目录规范

模型文件统一存储在 `models/` 目录下，结构如下：

```
models/
├── tts/
│   ├── kokoro-82m/
│   │   ├── model.onnx          # 主模型文件
│   │   ├── voices.bin          # 音色配置文件
│   │   └── voices/             # 音色嵌入文件
│   │       ├── xiaobei.bin
│   │       ├── yunjian.bin
│   │       └── ...
│   └── indextts25/
│       ├── model.onnx          # 主模型文件
│       └── voices/             # 音色嵌入文件
│           ├── zh-female-1.bin
│           ├── yue-male-1.bin
│           └── ...
├── asr/
│   ├── whisper-base/
│   │   ├── encoder.onnx    # 编码器模型
│   │   ├── decoder.onnx    # 解码器模型
│   │   └── tokens.txt      # 词汇表文件
│   └── whisper-small/
│       ├── encoder.onnx    # 编码器模型
│       ├── decoder.onnx    # 解码器模型
│       └── tokens.txt      # 词汇表文件
└── checksums.json              # 模型哈希校验文件
```

- `checksums.json` 存储每个模型文件的 SHA256 哈希值，格式：`{"文件相对路径": "sha256哈希"}`
- 手动导入模型时，用户需将文件放置到对应目录结构中，或通过 `votex model import` 命令自动归档

### 2. 语音合成 TTS（核心模块）

定位：文本转离线人声，适配小说朗读、视频旁白、短视频配音。

#### 2.1 文本编辑区

- 超大多行输入框，支持直接输入和拖拽导入 TXT 文档
- 内置文本预处理：
  - 去除空行（连续空行合并为 1 行）
  - 去除特殊符号（可配置保留/移除列表）
  - 数字转中文（如 "123" → "一百二十三"，可开关）
- 自动分段：按字数切分，提供 300 / 500 / 800 字三档可选
  - 分段策略：优先在句号、问号、感叹号、换行处切分，避免在词语中间截断
  - 兜底策略：当连续 800 字（最大档位）内无任何标点或换行时，在字数上限处硬切分，并在日志中记录警告
  - 每段独立合成，最终无缝拼接为完整音频

#### 2.2 语音参数区

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| TTS 引擎 | Kokoro / IndexTTS2 | Kokoro | 切换引擎后音色列表联动更新 |
| 音色 | 依赖引擎 | — | Kokoro: 8 种；IndexTTS2: 按官方列表 |
| 语速 | 0.5x ~ 2.0x | 1.0x | 步长 0.05 |
| 音调 | -20 ~ +20 | 0 | 半音微调 |
| 音量 | 0 ~ 100% | 80% | 输出音频整体音量 |

#### 2.3 操作按钮

- **试听**：合成前 500 字短片段，实时预览音色/语速效果。试听片段取前 500 字所在的完整段落（不会在段落中间截断），若首段不足 500 字则顺延至下一段
- **开始合成**：一键生成完整音频
- **暂停 / 继续**：支持长文本合成中途暂停。暂停粒度为段落级：当前正在合成的段落完成后暂停，已合成的段落音频缓存到临时目录，继续时从下一段开始
- **导出格式**：
  - WAV（无损，16bit/24bit PCM，采样率跟随模型）
  - MP3（有损，可配置比特率：128/192/256/320 kbps）
- 合成后选项：自动播放 / 打开输出目录

#### 2.4 音频播放器

- 内置轻量播放器，支持播放/暂停、进度条拖拽、音量调节
- 试听和合成完成后可直接在界面内播放预览
- 不依赖外部播放器，基于 rust-ffmpeg 解码 + 系统音频输出

#### 2.5 音频输出参数

| 参数 | Kokoro-82M | IndexTTS2 |
|------|-----------|-----------|
| 采样率 | 24000 Hz | 22050 Hz |
| 声道 | 单声道 | 单声道 |
| 默认位深 | 16bit PCM | 16bit PCM |

- MP3 输出时重采样为 44100 Hz（标准 MP3 采样率）
- WAV 输出保持模型原始采样率

#### 2.6 高级选项

- **无缝音频拼接**：
  - 默认开启，对相邻段落做交叉淡入淡出（crossfade 50ms）
  - 可自定义交叉时长（0 ~ 200ms）
- **段落间停顿时长**：0 ~ 2000ms（默认 300ms），模拟自然朗读停顿
- **背景降噪**：合成后对输出音频做轻量降噪（默认关闭，双引擎均可用；Kokoro 引擎使用频谱减法，IndexTTS2 引擎使用内置降噪）



### 3. 语音识别 ASR（核心模块）

定位：音频/视频转文字、自动生成字幕 SRT，适配视频剪辑、有声录音转文稿。

#### 3.1 文件导入区

- 支持格式：MP3、WAV、FLAC、MP4（自动提取音频轨）
- 拖拽上传、文件选择器导入
- 支持批量导入多个文件
- 显示文件信息：文件名、时长、大小、采样率

#### 3.2 识别参数区

| 参数 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| 模型 | base / small | base | small 准确度更高，推理时间约 2 倍 |
| 识别语种 | 简体中文 / 中英混合 | 简体中文 | 中英混合模式下中英文同时识别 |
| 自动添加标点 | 开 / 关 | 开 | 基于 Whisper 内置标点能力 |
| 长音频自动切片 | 开 / 关 | 开 | 超过 30 秒的音频自动切片后分段识别 |
| 切片时长 | 15s / 30s / 60s | 30s | 每段最大时长 |

#### 3.3 输出配置

- 导出格式：
  - 纯 TXT 文本（仅文字，无时间戳）
  - SRT 字幕（带时间戳，适配视频剪辑软件）
  - LRC 歌词字幕（带时间戳，适配音乐播放器）
- SRT 时间轴精度：毫秒级（格式 `HH:MM:SS,mmm`），基于 Whisper 输出的词级时间戳对齐
- SRT 时间轴对齐策略：使用 Whisper 内置的 word-level timestamp，按语义断句合并为字幕行，每行最长 20 字
- 预览识别结果：实时流式展示已完成的段落
- 手动二次编辑：识别完成后可在文本框内直接修改文字（GUI 支持 SRT 时间轴可视化编辑；CLI 仅输出文件，不支持交互编辑）

#### 3.4 视频文件处理

- MP4 文件导入时自动提取音频轨：使用 ffmpeg 提取为 WAV 临时文件（16kHz 单声道），提取完成后送入 ASR 引擎
- 临时音频文件存储在临时目录，识别完成后按配置周期自动清理
- 超长视频（>2 小时）提示用户确认，避免长时间占用资源

#### 3.5 降噪功能

- 识别前可选对输入音频做降噪预处理（默认关闭）
- 降噪算法：频谱减法（Spectral Subtraction），轻量级适合 CPU 推理
- 降噪强度：低 / 中 / 高三档可选
- 适用场景：去除环境噪音、键盘声、风扇声等

#### 3.6 操作按钮

- 开始识别 / 暂停 / 取消
- 清空结果
- 导出文件
- 打开输出目录



### 4. 批量任务

定位：重度创作者专用，批量处理大量文本/音频。

#### 4.1 批量 TTS

- 批量导入多个 TXT 文件
- 统一配置：音色、语速、音调、导出格式
- 每个文件独立设置分段参数（可继承全局默认）
- 一键全部合成，自动命名归档（使用源文件名 + 序号）
- 命名规则：`{源文件名}_{三位序号}.{扩展名}`，如 `chapter_001.mp3`、`chapter_002.mp3`
- 文件名冲突时自动追加序号后缀，如 `chapter_001_2.mp3`
- 进度面板：总进度 + 单文件进度 + 队列状态

#### 4.2 批量 ASR

- 批量导入音视频文件
- 统一配置：模型、语种、导出格式
- 一键批量生成对应字幕/TXT
- 进度面板：总进度 + 单文件进度 + 队列状态



### 5. 任务队列

全局任务队列，管理所有 TTS/ASR 执行任务。

- 排队策略：FIFO，单个任务按提交顺序执行
- 并发数：TTS 和 ASR 各 1 个并发（共用同一 CPU 推理资源）
- 每个任务状态：排队中 → 执行中 → 已完成 / 已失败 / 已取消
- 操作：暂停单个任务、取消单个任务、清空已完成任务
- 失败重试：自动重试 1 次（5 秒后），仍失败则标记为失败并记录错误日志
- 任务持久化：关闭程序时保留未完成任务列表，下次启动可选恢复执行
- 持久化格式：JSON 文件，存储在程序同级目录 `tasks.json`
- 持久化内容：任务 ID、任务类型（TTS/ASR）、输入文件路径、参数快照、已完成段落索引、状态
- 长文本合成失败续做：已完成的段落音频保留在临时目录，续做时从失败段落重新合成，已完成的段落直接拼接

#### 底部全局状态栏（常驻）

- TTS 模型状态 / ASR 模型状态（图标 + 文字）
- 当前任务进度条 + 阶段文字（如 "TTS 合成中：第 3/12 段"）
- 任务统计：排队 N / 已完成 N / 失败 N

软件默认启动页，新手指南面板。

- 模型状态卡片：TTS 模型状态、ASR 模型状态（就绪 / 未下载 / 加载中）

- 最近任务：展示最近 10 条合成/识别记录，可快速打开输出文件
  - 记录字段：任务 ID、类型（TTS/ASR）、输入文件名（脱敏）、输出文件路径、状态、创建时间、耗时
  - 存储格式：JSON 文件，存储在程序同级目录 `recent_tasks.json`

4. **完成页**：引导结束，进入首页

- 引导仅在首次启动触发，后续启动不再显示
- CLI 模式下首次运行时输出提示信息，引导用户执行 `votex model download`

### 10. 任务编排与流水线设计

定位：将 TTS、ASR 等独立模块编排为自动化流水线，一键完成多步骤任务。

#### 10.1 流水线类型

| 流水线 | 步骤 | 输入 | 输出 |
|--------|------|------|------|
| 有声书生成 | 文本分段 → TTS 合成 → 音频拼接 → 导出 | TXT 文件 | 完整有声书音频（WAV/MP3） |
| 字幕生成 | 音频切片 → ASR 识别 → 时间轴对齐 → 导出 | 音频/视频文件 | SRT/LRC 字幕文件 |
| 有声书+字幕 | 文本分段 → TTS 合成 → 音频拼接 → ASR 识别 → 字幕对齐 → 导出 | TXT 文件 | 有声书音频 + 同步字幕 |

#### 10.2 流水线执行模型

- 每个步骤作为独立阶段，阶段间通过中间产物（临时文件）传递数据
- 阶段状态：等待中 → 执行中 → 已完成 / 已失败
- 任一阶段失败，流水线暂停，用户可选择重试当前阶段或跳过
- 支持从失败阶段恢复执行，已完成的阶段不重复执行
- 流水线进度展示：总进度 + 当前阶段 + 阶段内进度

#### 10.3 渐进式质量策略

- 默认使用轻量配置快速完成任务，用户不满意时可升级重跑
- TTS 渐进策略：Kokoro（快速、普通话）→ IndexTTS2（更自然、方言支持）
- ASR 渐进策略：Whisper base（快速）→ Whisper small（更准确）
- 流水线完成后提示："对效果不满意？可切换至更高精度模型重新生成"
- 重跑时保留上一次的参数和分段信息，仅替换模型重新推理

#### 10.4 多 Provider 统一抽象

- TTS 引擎和 ASR 引擎统一抽象为 Provider 接口
- 每个 Provider 实现统一的生命周期：初始化 → 加载模型 → 推理 → 释放资源
- Provider 注册机制：新增引擎时只需实现接口并注册，无需修改上层逻辑
- v1 内置 Provider：
  - TTS：KokoroProvider、IndexTTS2Provider
  - ASR：WhisperProvider
- 后续版本可扩展在线 API Provider（如云端 TTS/ASR 服务）

### 11. 后续版本规划

#### 11.1 v1.x 增强

- 方言扩展：吴语、客家话等
- 流水线模板：用户可自定义流水线步骤组合
- 流水线预设：一键生成播客、一键生成有声书（含章节分割）

#### 11.2 v2 在线服务接入

- 支持接入在线 TTS/ASR API（通过 API Key 配置）
- 在线 Provider 与本地 Provider 统一抽象，用户可自由切换
- 支持的在线服务（规划）：

| 服务类型 | 候选服务 | 说明 |
|---------|---------|------|
| 在线 TTS | Azure Speech、阿里云语音合成 | 更自然的语音效果，需联网 |
| 在线 ASR | 阿里云语音识别、腾讯云 ASR | 更高准确度，需联网 |
| LLM 文案 | OpenAI、通义千问、DeepSeek | 自动生成/优化文案内容 |

- 在线 API Key 通过配置文件管理，不硬编码
- 混合模式：本地模型 + 在线 API 可组合使用（如本地 TTS + 在线 ASR）

#### 11.3 v2 自动化短视频生成

- 基于 LLM + TTS + ASR + 素材合成的全自动短视频流水线
- 输入主题/关键词 → LLM 生成文案 → TTS 合成配音 → ASR 生成字幕 → 素材合成 → 输出视频
- 需要在线 API 支持（LLM 文案生成、素材获取）
- 本地模式：用户提供文案 + 本地素材，仅使用本地 TTS/ASR

#### 11.4 跨平台与架构演进

- Tauri2 前后端分离架构（为跨平台做准备）
- Linux / macOS 支持
