## 流水线任务

流水线（Pipeline）是多步骤任务编排的聚合根，支持有声书生成、字幕生成、有声书+字幕混合流水线。

### 1. 流水线类型

| 类型 | 阶段序列 | 用途 |
|------|---------|------|
| Audiobook | 文本预处理 → 文本分段 → TTS 合成 → 音频拼接 → 导出 | 小说/文章转有声书 |
| Subtitle | 音频提取 → 音频切片 → ASR 识别 → 字幕对齐 → 导出 | 音视频转字幕 |
| AudiobookWithSubtitle | 文本预处理 → 文本分段 → TTS 合成 → 音频拼接 → ASR 识别 → 字幕对齐 → 导出 | 有声书 + 字幕 |

### 2. 实体模型

**Pipeline（聚合根）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | PipelineId | 流水线唯一标识（UUID v4） |
| kind | PipelineKind | 流水线类型 |
| stages | Vec\<Stage\> | 阶段列表 |
| status | PipelineStatus | 当前状态 |
| input | PipelineInput | 输入参数 |
| output | Option\<PipelineOutput\> | 输出结果 |
| created_at | String | 创建时间 |

**Stage**

| 字段 | 类型 | 说明 |
|------|------|------|
| index | usize | 阶段序号 |
| kind | StageKind | 阶段类型 |
| status | StageStatus | 阶段状态 |
| artifact_path | Option\<PathBuf\> | 中间产物路径 |

### 3. 持久化

#### 3.1 存储方案

使用 SQLite `pipelines` 表，JSON-in-column 模式：

```sql
CREATE TABLE pipelines (
    id          TEXT PRIMARY KEY,
    data_json   TEXT NOT NULL,
    status      TEXT NOT NULL DEFAULT 'Idle',
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);
CREATE INDEX idx_pipelines_status ON pipelines(status);
```

#### 3.2 保存时机

`PipelineUseCase` 在以下时机自动保存流水线状态：

```
开始执行前     → save(Idle)     — 记录流水线已创建
每阶段完成后   → save(Running)  — 记录当前进度 + 已完成阶段信息
阶段失败时     → save(Failed)   — 记录失败阶段和错误信息
全部完成时     → save(Completed) — 记录最终状态
```

#### 3.3 启动恢复

应用启动时调用 `find_incomplete()` 查找所有 `Idle / Running / Paused` 状态的流水线：

```rust
let incomplete = repo.find_incomplete();
for pipeline in incomplete {
    tracing::info!("发现未完成流水线: {} (状态: {:?})", pipeline.id, pipeline.status);
    // 由用户选择是否恢复执行
}
```

### 4. CLI 用法

```bash
# 有声书生成
votex pipeline --kind audiobook --input novel.txt --output output/

# 字幕生成
votex pipeline --kind subtitle --input audio.wav --output output/

# 有声书+字幕
votex pipeline --kind audiobook-sub --input novel.txt --output output/
```

流水线数据自动持久化到 `data/votex.db`（与 TTS/ASR/OCR 任务共用同一数据库文件）。
