# 实时能力实施方案

## 概述

本文档定义 votex（声阅）实时翻译能力的实施方案。分三个阶段迭代推进：

| 阶段 | 功能 | 目标延迟 | 预估工期 |
|:----:|------|:--------:|:--------:|
| Phase-1 | 准实时文本翻译 | 逐句输出 < 1s | 2-3 天 |
| Phase-2 | 视频翻译字幕 | 离线批次处理 | 5-7 天 |
| Phase-3 | 语音实时翻译 | 端到端 < 3s | 8-12 天 |

### 1.1 新增流式翻译接口

**文件**：`crates/votex-domain/src/translation/provider.rs`

```rust
use tokio::sync::mpsc;

pub trait TranslationProvider: Send + Sync {
    fn name(&self) -> &str;

    /// 一次性翻译（保留，兼容现有调用方）
    fn translate(&self, text: &str, direction: TranslationDirection)
        -> Result<String, TranslationError>;

    /// 流式翻译：逐句推送翻译结果
    fn translate_stream(
        &self,
        text: &str,
        direction: TranslationDirection,
    ) -> mpsc::UnboundedReceiver<Result<String, TranslationError>> {
        // 默认实现：一次性翻译后推送完整结果
        let (tx, rx) = mpsc::unbounded_channel();
        let _ = tx.send(self.translate(text, direction));
        rx
    }
}
```

各 Provider 覆写 `translate_stream` 实现分句 → 逐句翻译 → 逐句推送。

### 2.2 流水线阶段序列

```
PipelineKind::VideoSubtitle:
  [0] AudioExtract    → ffmpeg 提取音频（16kHz 单声道 WAV）
  [1] AudioSlice      → VAD/定时切片（复用现有 AudioSlice 处理器）
  [2] AsrRecognize    → 逐片 ASR 识别（复用现有 AsrRecognize 处理器）
  [3] Translate       → 逐句翻译，复用 ASR 时间轴（新增处理器）
  [4] SubtitleAlign   → 生成双语 SRT（复用 + 扩展）
  [5] BurnSubtitle    → ffmpeg 烧录字幕到视频（新增处理器）
  [6] Export          → 输出视频文件（复用）
```

### 2.3 处理器实现

#### AudioExtractHandler

```rust
// 调用 ffmpeg 提取音频
ffmpeg -i input.mp4 -vn -ar 16000 -ac 1 output.wav
```

使用 `std::process::Command` 调用系统 ffmpeg（项目已有 `ffmpeg` feature flag）。

#### TranslateHandler

输入：ASR 识别结果（`StageParams.segments: Vec<String>` + 时间戳）
处理：逐句调用 `TranslationProvider::translate`，时间戳保持不变
输出：翻译文本数组（与原文时间轴一一对应）

#### BurnSubtitleHandler

```rust
// 硬字幕烧录
ffmpeg -i input.mp4 -vf "subtitles=subtitle.srt:force_style='FontName=...'" output.mp4

// 软字幕嵌入
ffmpeg -i input.mp4 -i subtitle.srt -c copy -c:s mov_text output.mp4
```

### 3.3 流式 ASR 实现

#### 主方案：sherpa-onnx OnlineRecognizer

**文件**：`crates/votex-infra/src/asr/online/recognizer.rs`

sherpa-onnx 已提供 `OnlineRecognizer` API，支持 Zipformer2、Parakeet 等模型。无需新增依赖。

```rust
pub struct OnlineSenseVoiceProvider {
    recognizer: Mutex<Option<OnlineRecognizer>>,
    sample_rate: u32,
}

impl StreamingAsrProvider for OnlineSenseVoiceProvider {
    fn recognize_stream(
        &self,
        params: &AsrParams,
    ) -> (mpsc::UnboundedSender<Vec<f32>>, mpsc::UnboundedReceiver<StreamingResult>) {
        let (audio_tx, mut audio_rx) = mpsc::unbounded_channel();
        let (result_tx, result_rx) = mpsc::unbounded_channel();

        // 后台任务：接收音频 → 喂入 OnlineStream → 逐句回调 → 推送结果
        tokio::spawn(async move {
            let stream = recognizer.create_stream();
            while let Some(chunk) = audio_rx.recv().await {
                stream.accept_waveform(16000, &chunk);
                recognizer.decode(&stream);
                while let Some(text) = stream.get_result() {
                    let _ = result_tx.send(StreamingResult {
                        text,
                        is_final: true,
                        start_ms: 0.0,
                        end_ms: 0.0,
                    });
                }
            }
        });

        (audio_tx, result_rx)
    }
}
```

### 3.4 实时翻译管线编排

**文件**：`crates/votex-infra/src/translation/realtime.rs`

```rust
pub struct RealtimeTranslateService {
    asr: Box<dyn StreamingAsrProvider>,
    translator: Box<dyn TranslationProvider>,
    direction: TranslationDirection,
    output_subtitle: mpsc::UnboundedSender<StreamingResult>,
    output_audio: Option<mpsc::UnboundedSender<AudioData>>,
}

impl RealtimeTranslateService {
    /// 启动实时翻译管线
    /// 返回音频输入通道 + 字幕输出通道
    pub fn start(
        &mut self,
    ) -> Result<(
        mpsc::UnboundedSender<Vec<f32>>,   // 音频输入
        mpsc::UnboundedReceiver<String>,    // 翻译文本输出
    ), RealtimeError>;

    /// 停止管线
    pub fn stop(&mut self);

```

管线内部流程：

```
音频输入 (mpsc::Sender<Vec<f32>>)
    │
    ▼
[VAD 检测] ──静音──→ 丢弃
    │ 有语音
    ▼
[音频积累] ──800ms 窗口──→ OnlineRecognizer
    │ 完整句子回调
    ▼
[翻译引擎] ──translate_stream──→ 逐句翻译结果
    │
    ├──→ [字幕输出] (mpsc::Receiver<String>)
    │
    └──→ [TTS 合成] ──cpal──→ 音频播放（可选）
```

### 3.5 延迟预算

| 环节 | 延迟 | 说明 |
|------|:----:|------|
| 音频捕获 + 环形缓冲 | ~100ms | 每 100ms 推一个切片 |
| VAD 检测 | ~10ms | Silero VAD ONNX 推理 |
| ASR 识别 | ~500ms | OnlineRecognizer 逐句，模型约 50ms/100ms 音频 |
| 翻译 | ~500ms | HY-MT1.5 单句推理 |
| TTS 合成（可选） | ~500ms | 短句合成 |
| 播放缓冲 | ~200ms | 防卡顿 |
| **合计** | **~1.8s** | 不含 TTS 约 1.1s |
